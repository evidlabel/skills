# documents

From the case root, `evid --db evid`.
The commands are `evid -h` and `evid -j`.

The cache takes documents from the internet, from local evid databases, and from the public fetch tools under `sources` (lawcite, domdb, hudoc).

Import from a global cache, a url, or a directory.
Sync a document upstream to a shared cache when the case calls for it.

A later stage searches this cache and quotes it by key.
