
- principles
    - micro skill tree
    - tree structure important information, think about correct naming, hierarchy and depth
    - use git to track and merge and create time dimension in tree

- good micro skill writing
    - one topic only
    - maximally clear formulation
    - plain english
    - use nested bullet points
    - use short sentences
    - if needed, use # markdown chapters, but consider instead making two skills
    - clear name, steno description
    - avoid being source of truth, rather instruct how to establish source of truth
        - example: 
            - bad --> ICD11 has NPD and BPD as clustered personality disorders in cluster B (makes a statement about ICD11) 
            - good --> obtain list of what is generally referred to as cluster B disorders from the diagnostic websites like ICD, for the relevant jurisdiction and timeframe (tells agent to obtain disorder list from ICD11)
    - write for reasonable and knowledgeable human (assume agents will work well on this standard in due time)
    - avoid writing bossy or jarring language (old pattern to try to force LLMs) 
    - avoid writing mistakes, anti patterns etc (creates verbosity and unclarity for humans)
